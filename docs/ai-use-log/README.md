# AI-use log (BRD section 5.4)

Keep this current. One file per developer, named `<yyyy-mm-dd>-<name>.md` or one running file per person, so we never get merge conflicts.

For each use record:
- **Tool and account:** an approved tool, signed in with your work account.
- **What was shared:** made-up examples only. Never trainee-style records, secrets or keys.
- **What came back and where it went:** which file or function, and that you reviewed and can explain every line.

Expect the TPM to ask to see your AI-tool history (Days 3 and 5).
